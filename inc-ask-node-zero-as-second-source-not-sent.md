**Subject:** Node zero: a date, and a name I'd like to use

Dear Geert,

A concrete step on the piece we agreed in principle: INC's own memory running on infrastructure it owns, node zero.

I'm building the layer that lets independently hosted sources find each other, cite each other by unit rather than by URL, and decide per record what is public, what peers may see, and what never leaves. That is the mechanism the working document promised in paragraph four, and it needs two sources that are not the same source to prove anything. Mine is yeehaa.io. The second should be INC's: the archive and the record, on a networkcultures.org subdomain, operated by me, with the visible surface entirely in INC's own terms. You would have to write nothing and run nothing. Your publishing tools are not touched.

Timing: the layer gets built from mid November; the two-source demonstration runs in March and April 2027. What I'd need from INC is one DNS record when we get there, and one person to say yes to that.

The reason I ask now rather than in March: SIDN fonds has invited a Pioniers application for exactly this layer, and I'd like to name INC in it as the operator of the second source, as it is: the institute that spent twenty-two years theorising networks, becoming one. I won't name INC without your yes. A one-line reply is enough.

Best,

Jan Hein

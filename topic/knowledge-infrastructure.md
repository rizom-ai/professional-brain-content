---
title: Knowledge Infrastructure
---
Personal and shared brains provide portable, self-hosted knowledge infrastructure for crowdlearning and collaborative practice. Participants maintain individual knowledge spaces while cohorts build collective memory around shared questions, using agent runtimes, MCP services, plugins, markdown and Git workflows, synchronization, multi-tenant provisioning, onboarding materials, site generation, deployment tooling, and group-oriented workshops. This foundation reduces the engineering required for renewed deployment and supports both public-interest open learning infrastructure and institutional learning services. The key remaining work is not basic hosting, but federation, consent-based exchange, and effective cohort curation workflows for contributing, reviewing, and surfacing collective knowledge. The approach builds on substantial prior development, operational experience, and accumulated provenance. Keywords: personal knowledge spaces, shared brains, crowdlearning, collaborative curation, cohort learning, self-hosted infrastructure, federation, consent-based exchange, agent runtimes, MCP, Git workflows, synchronization, multi-tenant provisioning, open learning infrastructure.

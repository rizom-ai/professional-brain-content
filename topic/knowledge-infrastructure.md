---
title: Knowledge Infrastructure
---
Open-source, self-hosted infrastructure for preserving, coordinating, and sharing knowledge across individuals, cohorts, and institutions. Personal knowledge spaces and shared brains support crowdlearning, collaborative curation, and institutional memory while keeping data, context, and operational history under organizational control rather than with vendor-hosted AI services. The technical foundation includes agent runtimes, MCP servers, TypeScript, Bun, OAuth, plugin systems, Markdown and Git workflows, synchronization, multi-tenant provisioning, onboarding, site generation, and deployment tooling. The broader challenge is federation, consent-based exchange, and effective workflows for contributing, reviewing, and surfacing collective knowledge. This domain builds on prior open-source projects, operational experience, and accumulated provenance to reduce the engineering required for renewed deployments in public-interest and institutional learning contexts. Keywords: personal knowledge spaces, shared brains, crowdlearning, institutional memory, collaborative curation, self-hosted AI, data sovereignty, agent runtimes, MCP servers, plugin systems, OAuth, Git workflows, federation, consent-based exchange, multi-tenant provisioning, open learning infrastructure

---
title: 'Portable, Federated Knowledge Infrastructure'
---
The content presents self-hosted AI brains as portable knowledge infrastructure owned and controlled by individuals, teams, and institutions. Each participant can maintain a personal brain while contributing selected knowledge to a shared cohort brain by consent. This model extends Offcourse’s crowdlearning thesis into a system based on markdown, Git, MCP, agents, per-user provisioning, and bidirectional synchronization. The infrastructure emphasizes data ownership, provenance, selective visibility, and the ability to work through ordinary text repositories with optional tools such as Obsidian. Existing capabilities include an MCP server, OAuth, plugin support, site generation, deployment tooling, multi-tenant provisioning, and a live agent registry. The main unfinished areas are cross-brain selective sharing, constellation formation, and group curation workflows. Together, these elements frame institutional memory as an open, federated alternative to vendor-controlled knowledge systems.
